# Architecture Decision Records

Un ADR consemnează context, decizie, statut și consecințe. `Accepted` descrie direcția acceptată; nu pretinde implementare. `Proposed` cere validare înaintea implementării. Modificările arhitecturale trebuie să numească ADR-ul înlocuit.
