# Weather data attribution

Weather data are provided by [Open-Meteo](https://open-meteo.com/) under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). Provider licence: https://open-meteo.com/en/licence.

PySH formats and rounds values, translates weather descriptions and derives decorative sky states from forecasts. Readings are not independently measured by PySH.

Clickable provider credit sits adjacent to displayed location/weather in Home weather cards, including compact/editing states, forecast headers and weather settings. Settings also provide the licence and transformation statement. Open-Meteo requires a link next to each location displaying its data. PySH interprets this as visible locations/readings/forecasts; the idle sky contains no location or figures and keeps the user's clock-and-signal-only design. This interpretation is not a provider-issued exemption. Future weather/location surfaces need adjacent credit.

The broker accepts only fixed identifiers `open-meteo` and `cc-by`, without pausing radio or entering DRM preparation. An owned Chromium window has a persistent 48px Back control. Exact HTTPS origins are `open-meteo.com` and `creativecommons.org`. Unsupported links, redirects, new tabs and network failures recover to an extension-owned Back page. Navigation observation does not grant arbitrary backend/native destinations. A redirect can initiate an external request before recovery; the observer is not a firewall.

Native process return, radio continuity, navigation recovery and physical touch remain hardware acceptance checks. Isolated fixtures do not prove them.
