# Physical SD SSH flash

2026-10-03. The owner explicitly authorized SD erasure, then inserted it while Raspberry remained running from USB. [Full original backup](sd-backup-2026-10-03.md) was independently verified before writing. USB remains the recovery medium; its root was not written.

The visible Windows console ran the production PC flasher as the owner, using strict SSH host verification and explicit recovery key. A dry-run verified image, full backup, receipt, physical CID and capacity. The same arguments then ran with `--write` against `/dev/mmcblk0`, CID744a60555344553120430a4e5f018100,15,962,472,448 bytes. Raw-image SHA256 before provisioning matched **de085cdcae326cfafba7ef93c2bf4956efd33aaf650ccdbb4a5cd311f3db5979**. Final raw bytes are intentionally changed by this provisioning; they are not claimed to retain the raw-image hash.
