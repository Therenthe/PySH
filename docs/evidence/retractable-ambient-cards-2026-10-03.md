# Retractable ambient cards

Owner requested an edge-following menu control, independently retractable weather/forecast, playback collapsing into a larger audio visualizer, station artwork, weather-driven clouds/precipitation and a taller city skyline. Candidate37e229ac1e15 contains41 runtime files; native activation and inspection are pending.

The menu control is positioned4px from the viewport edge when closed and55px when open, synchronized with the220ms rail transition. The closed rail releases107px. Each Home card has its own15-second inactivity timer, renewed by that card's interactions rather than the one-second API/clock updates. Weather hides the metric column and halves its500px maximum width; forecast changes between one and five days. Playback collapses into the88px-high signal surface, opened or closed by touching that surface; expanded visualization is48px high. With visualization explicitly disabled, a compact playback dock retains Play/Pause instead of presenting a false signal.

Station artwork reuses the catalog's optional HTTPS logo handling and falls back to a monogram. Optional artwork metadata persists with the last station, survives recovery of the same URL and clears when changing to an unrelated station. The backend does not fetch artwork. Current weather categories independently control clouds and visible nighttime moon/stars. Rain/snow layers pass over the170px city skyline. Missing/stale weather shows a neutral scene; reduced motion disables scene/card animations.

276 backend tests passed with22 platform skips and one existing Starlette warning.48 dedicated browser cases cover EN/RO, both themes, six weather scenes, visualization on/off, timers surviving clock updates, reopened timers, one/five-day switching, logo availability and completed width transitions. TypeScript, build and repository structure passed. Full browser regression is pending.

An initial timing assertion read the navigation transition before it completed; it was changed to wait for the final measured position. An intermediate full run exposed empty artwork metadata changing legacy play requests; the UI now omits absent optional artwork. That run also included development hot reload during the correction and is not full regression evidence. A fresh run on unchanged source is required. Native interaction checks and visual review remain necessary; automated fixtures do not prove real audio, physical touch latency or product acceptance. All30 criteria remain OPEN.
